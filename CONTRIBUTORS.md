# Contributors

SoLouder is a port of [SoLoud](https://github.com/jarikomppa/soloud). Almost
everything it does was designed and written by the people below. They are
credited for the original C++ work; they did not take part in SoLouder and
are not responsible for it.

## SoLoud creator

- **Jari Komppa** ([@jarikomppa](https://github.com/jarikomppa)): created SoLoud and wrote most of it

## Unmerged upstream pull requests used in the reference

These fixes were proposed upstream but never merged. SoLouder's C++ reference
applies them, or a variant noted in the patch; each file in
`reference/patches/` names its source.

- Jake S. Del Mastro ([@pgrAm](https://github.com/pgrAm)): WavStream channel stride and looping `hasEnded`, [PR #379](https://github.com/jarikomppa/soloud/pull/379)
- Yotam Gingold ([@yig](https://github.com/yig)): non-copyable `Wav`, [PR #375](https://github.com/jarikomppa/soloud/pull/375)
- Konstantin S. Matveyev ([@valid-ptr](https://github.com/valid-ptr)): diagnosis of the pre-init voice-array crash, [PR #345](https://github.com/jarikomppa/soloud/pull/345)

Third-party code bundled with SoLoud (decoders, Freeverb, sfxr, speech, and
others) has its own authors; see [THIRD_PARTY.md](THIRD_PARTY.md).

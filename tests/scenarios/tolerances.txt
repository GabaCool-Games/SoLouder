# Declared tolerances for comparisons with output from another platform:
# `scripts/run_parity.py --profile <name>` (see README.md, "Platforms").
# Scenarios not listed under the profile must match exactly, as on Windows.
# A declared tolerance can only loosen a scenario: the comparison uses the
# larger of the scenario's own `tolerance` and the one declared here.
#
# profile  scenario          max abs diff  # why
#
# `gcc`: Rust against a GCC/glibc build of the C++ reference (Debian 13,
# GCC 14.2, glibc 2.41, x86-64; measured 2026-10-19 on all 56 scenarios).
# Rust follows the MSVC build. Three causes, each confirmed by changing that
# line in a GCC build and seeing its scenarios match the Windows output:
# - stb_vorbis defines its own float M_PI only `#ifndef M_PI`; glibc's
#   <math.h> defines M_PI (a double), MSVC's does not without
#   _USE_MATH_DEFINES, so the GCC build computes the IMDCT twiddle factors and
#   the window with a different pi. Every Ogg decode differs in the last bits.
# - speech/resonator.cpp: `exp(arg)` and `cos(arg)` of a float resolve to
#   libstdc++'s float overloads (expf, cosf) where MSVC widens to double. The
#   resonator coefficients differ in the last bit; klatt truncates its output
#   to 16 bits, so a sample now and then lands one step (1/32768 before the
#   voice's gain) away.
# - filter/soloud_fftfilter.cpp: `cos(pha)` and `sin(pha)` of a float resolve
#   to the float overloads (GCC fuses them into sincosf). Its `atan2` of floats
#   also resolves to atan2f, but changes no sample in these scenarios.
# Measured maxima in brackets.
gcc        filters_spectral  1e-6    # FFT filter's sincosf [3.9e-7, 2321 of 32577 samples]
gcc        ogg_decode        5e-4    # stb_vorbis's pi, long loud files [1.2e-4, 623804 of 743882]
gcc        stream_ogg        1e-5    # stb_vorbis's pi, streamed [1.4e-6, 65639 of 78752]
gcc        spatial_sources   1e-6    # its Ogg stream [6.0e-8, 25624 of 49814]
gcc        file_loading      1e-6    # its Ogg files [3.3e-7, 67530 of 159084]
gcc        speech            3.1e-5  # one 16-bit step from resonator cosf/expf [1.8e-5, 10 of 784866]
gcc        generator_queues  3.1e-5  # its queued speech, as above [1.8e-5, 2 of 208896]
#
